# RONA Trade owner acceptance package

Implementation branch for the approved Admin / Client / Agent owner-acceptance package.

Canonical portal source files, brand assets, color system, background, visual identity, authority model, and AI-role separation remain unchanged. Business simplification is delivered through same-origin authenticated runtime adapters and the dedicated `rona-owner-acceptance` server contour.

Acceptance areas: Admin dashboard, prices, requests, deals/documents, payments, cash, claims regression, online rail, radio room, analytics, market news, access management, agent-company assignment, client contract download, agent PDF price list, and logout regression.
