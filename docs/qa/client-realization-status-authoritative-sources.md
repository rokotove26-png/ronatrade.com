# Authoritative sources for client realization status

- Registration: accessible authoritative deal record.
- Documents: current active confirmed/verified signed addendum referenced by owner deal workflow.
- Payment: latest active confirmed/verified owner deal finance summary.
- Resource: latest explicit resource decision; generic EXECUTING status does not confirm resource.
- Shipment and delivery: latest active confirmed/verified shipment.
- Closing: deal accounting closure status and closed timestamp.

The browser renders the server-projected result only and does not parse human-readable card text to infer business state.
